# E-Commerce Retail Data Analysis — NovaMart

An end-to-end retail data analysis project using **Python, SQL, and Tableau** on a fictional e-commerce dataset.

## 📌 Project Overview

NovaMart is a fictional e-commerce/retail business created to simulate a real-world Data Analyst project.

The project covers the complete analytics workflow — from understanding and validating raw data to analysis, visualization, dashboard development, and final quality assurance.

The analysis focuses on **sales performance, profitability, customers, products, sellers, and operational performance**.

---

## 🎯 Business Objectives

The project aims to answer questions such as:

* How is NovaMart performing in terms of sales, profit, and profit margin?
* Which regions and product categories generate the most sales?
* Which customer segments contribute most to the business?
* Which products and product subcategories perform best?
* Which sellers and seller types generate the strongest results?
* Which regions have the highest profitability?
* Which products have the highest sales and profit margins?
* What patterns exist across payment methods, shipping modes, and order statuses?

---

## 🗂️ Dataset

The project contains five related datasets:

| Dataset     |    Rows | Description                                                              |
| ----------- | ------: | ------------------------------------------------------------------------ |
| Customers   |   2,000 | Customer demographic and location information                            |
| Products    |     420 | Product, category, brand, cost, and pricing information                  |
| Sellers     |     100 | Seller information, type, and region                                     |
| Orders      |  50,000 | Order-level information including date, status, payment, and shipping    |
| Order Items | 105,953 | Transaction-level product, quantity, sales, cost, and profit information |

The **Order Items** dataset is the primary transactional table used for sales and profitability analysis.

## 📈 Key Results

| Metric                |  Result |
| --------------------- | ------: |
| Total Sales           | ₹2.107B |
| Total Profit          | ₹635.1M |
| Overall Profit Margin |   30.1% |

### Key observations

* Sales and profitability vary across regions and product categories.
* Seller performance differs significantly across sellers, seller types, and seller regions.
* Products with the highest sales are not necessarily the products with the highest profit margins.
* Product subcategories show differences in both sales contribution and profitability.
* Customer segments have different sales and profitability characteristics.
* Payment, shipping, and order-status analysis provides additional operational insights.
